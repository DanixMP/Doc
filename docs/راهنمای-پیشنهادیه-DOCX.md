# پیشنهادیه فارسی DOCX

## فایل اصلی
`پیشنهادیه-سامانه-هوشمند-پاپ-اسمیر.docx`

## قلم وزیرمتن (Vazirmatn)
برای نمایش صحیح در Microsoft Word / LibreOffice، قلم‌های داخل پوشه `fonts/` را نصب کنید:

- Vazirmatn-Regular.ttf
- Vazirmatn-Medium.ttf
- Vazirmatn-Bold.ttf
- Vazirmatn-Light.ttf

سپس سند را باز کنید. سند با چینش RTL و نام قلم `Vazirmatn` ساخته شده است.

## بازتولید
```bash
python3 scripts/build_persian_proposal_docx.py
```
