# Page 3 — تولیدات / اجرایی‌ات — printed page ۲

## تولیدات (Productions)
1. طراحی و تولید انواع چیلرهای تراکمی آب‌خنک و هواخنک
2. طراحی و تولید انواع برج‌های خنک‌کننده
3. طراحی و تولید انواع هواساز، هواسازهای هایژنیک و ایرواشر
4. طراحی و تولید انواع روفتاپ پکیج (Package Unit)
5. طراحی و تولید انواع لامینار باکس
6. طراحی و تولید انواع فیلتر هپا (HEPA)
7. طراحی و تولید انواع بویلر صنعتی، کویل و فن‌کویل
8. طراحی، تولید، اجرا، تعمیر و نگهداری انواع سیستم‌های تهویه مطبوع، داکت اسپلیت، کولر و غیره

## اجرایی‌ات (Operations / Execution)
1. طراحی و اجرای صفر تا صد انواع پروژه‌های ساختمانی
2. طراحی، محاسبه، اجرا و تجهیز انواع سوله‌های صنعتی
3. طراحی و اجرای انواع کلین‌روم (Clean Room)
4. طراحی، اجرا، تأمین، تجهیز و نگهداری انواع سیستم‌های موتورخانه مکانیکال
5. طراحی و اجرای سیستم‌های برق قدرت، شبکه روشنایی و دوربین مداربسته (CCTV)
