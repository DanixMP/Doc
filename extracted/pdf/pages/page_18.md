# Page 18 — یونیت هیتر — printed page ۱۷

**Title:** یونیت هیتر

برای گرمایش فضاهای بزرگ با سقف بلند (سالن ورزشی، سوله صنعتی، استخر). اجزا: بدنه، فن، کویل.
- بدنه استاندارد ورق گالوانیزه با پوشش پودری؛ گزینه آلومینیوم یا استنلس برای محیط خورنده/رطوبت بالا
- فن محوری ۷ پره؛ امکان موتور ضد انفجار
- کویل آب گرم یا بخار
- ظرفیت حدود ۴۲٬۰۰۰ تا ۴۵۰٬۰۰۰ BTU/hr؛ موتور تک‌فاز یا سه‌فاز؛ سرعت حدود ۷۰۰ تا ۲۹۰۰ RPM
