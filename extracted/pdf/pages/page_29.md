# Page 29 — طبقه‌بندی اتاق تمیز — printed page ۲۸

**Title:** طبقه‌بندی اتاق تمیز

بحث انتقال از استاندارد فدرال آمریکا 209 (A–D) و 209E به ISO 14644-1؛ طبقه‌بندی بر اساس تعداد و اندازه ذرات در فوت مکعب یا متر مکعب؛ اشاره به BS 5295 در بریتانیا؛ مثال‌هایی مانند Class 100 / Class 1000 و معادل ISO.

## ISO 14644-1 Cleanroom Standards (key points)
| Class | FED STD 209E equiv | notes |
|---|---|---|
| ISO 1 | — | e.g. 10 /m³ @ >=0.1 µm |
| ISO 5 | Class 100 | e.g. 3520 /m³ @ >=0.5 µm |
| ISO 7 | Class 10,000 | e.g. 352000 /m³ @ >=0.5 µm |
| ISO 9 | Room Air | e.g. 35,200,000 /m³ @ >=0.5 µm |

Particle size columns include >=0.1, 0.2, 0.3, 0.5, 1, 5 µm.
